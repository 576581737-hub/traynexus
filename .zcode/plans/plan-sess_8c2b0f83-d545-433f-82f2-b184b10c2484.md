# Traynexus 功能落地实现计划

## 目标
按 HTML 设计稿把功能真正接通到 C# 后端，同时把图标重做为 `logo.svg` 的渐变玻璃风。HTML 界面与演示逻辑保持不变，只替换其内部的 mock 数据/假动作为真实桥接调用。

## 核心原则
- **HTML 外观和交互流程不动**：所有 CSS、布局、对话框、动画时序、Ultracode 引擎保持原样
- **只改 `<script>` 段**：把 mock 函数改为调用 `TraynexusBridge`，把写死数据改为运行时拉取
- **C# 后端按需扩展**：补电池采集、OEM 充电 WMI、桥接新方法

## 第一部分：图标重做（落实 logo.svg 设计）

### 1.1 重写 `IconRenderer.cs` — 渐变玻璃风
当前是纯色扁平圆环，改为对齐 `logo.svg`：
- **玻璃底板**：64px 圆角方块（rx≈18），`LinearGradient` 浅色渐变填充 + 白色描边 + 投影
- **外环（内存）**：橙色 `LinearGradient`（`#fcd34d→#f97316→#ea580c`），描边 5px，圆角端点
- **内环（电池）**：绿色 `LinearGradient`（`#6ee7b7→#059669`），描边 4px
- **轨道**：`#cbd5e1` 浅灰（替换当前 `#3C3C3C` 深灰，与 logo 一致）
- **闪电**：黄色 `LinearGradient`（`#fef08a→#facc15→#eab308`）+ 暗黄描边 + 中心高光椭圆
- 保持现有三级缓存机制 `(memPercent, battLevel, isCharging)` 不变

### 1.2 生成新 `resources/tray_default.ico`
从 `logo.svg` 渲染多尺寸 ico（16/32/48/64/128/256），替换当前 259KB 的旧文件。构建脚本 `/win32icon` 引用不变。

## 第二部分：电池电量真实采集（P0）

### 2.1 新增 `BatteryInfo.cs`
- WMI 查询 `SELECT * FROM Win32_Battery`
- `BatterySnapshot` 类：`Percent`(int)、`IsCharging`(bool)、`IsPresent`(bool)
- `static BatterySnapshot Take()` 方法，失败时返回 `IsPresent=false`
- 设计容量/循环次数/温度等 Win32_Battery 通常拿不到 → 维持占位

### 2.2 改 `BridgeApi.GetBatteryInfo()`
返回真实 `BatteryInfo.Take()` 数据（当前是写死的 `{"percent":0}`）。

### 2.3 改 `TrayContext.cs`
- 填充 `BatteryTick()` 空桩：调 `BatteryInfo.Take()`，存到字段 `_battery`
- `TickRefresh` 里 `IconRenderer.Build(mem, _battery.Percent, _battery.IsCharging)`（当前硬编码 `0,false`）
- 托盘文字 `电量 --` → 真实百分比
- 新增推送：`_webViewPanel.PostMessage("{\"type\":\"battery\",\"data\":...}")`

## 第三部分：前端接线（核心 — 让 HTML 演示变成真实功能）

### 3.1 启动时引导加载（新增 `bootstrap()` 函数）
页面加载后并行调用：
- `getMemorySnapshot()` → 填充速览面板内存数字、概览卡片、标题栏、托盘 tooltip、`initUltracode` 的 percent
- `getBatteryInfo()` → 填充速览面板电池、概览电池卡片、电池 Ultracode
- `getSettings()` → 回填充电模式高亮、阈值、释放方式开关状态
- `getAutoStartState()` → 回填自启开关
- `previewTargets()` → 填充释放面板进程表
- `checkMigration()` → 检测旧 MemTrayCN 配置（有则 toast 提示）

### 3.2 Ultracode 引擎动态化
`initUltracode` 的 `percent` 当前闭包捕获一次。改为读取全局可变变量：
- 新增 `window.__memPct = 36` / `window.__battPct = 78`
- `tick()` 内 `scanProgress` 改读 `window.__memPct/100`
- `bootstrap()` 和 `onMessage` 推送时更新这两个变量

### 3.3 替换 mock 函数为桥接调用（逐个对应）

| HTML 函数 | 改造内容 |
|---|---|
| `quickRelease(btn)` | 旋转圈阶段调 `executeRelease()`，用返回的 `freedDisplay`/`afterDisplay` 更新对号文案；失败显红 |
| `rpRender()` | 删 `PROCS` 数组，改调 `previewTargets()` 渲染真实进程；字段映射 `name/pid/workingSetDisplay/protected/protectReason` |
| `rpExec()` | 调 `executeRelease()`，用 `trimmedCount`/`freedDisplay` 填结果弹窗 |
| `rpPersist()` | 调 `saveWhitelist()` 把勾选的"内存保持"进程持久化 |
| `rpReload()` | 调 `previewTargets()` 重新拉取 |
| `selMode(m)` | 末尾追加 `updateSettings()` 持久化充电模式 |
| `bcSync()` | 滑块改变时持久化充电上限 |
| `toggleMode(type)` | 三开关切换后持久化释放方式（扩展 Settings） |
| 阈值对话框"确定" | 调 `updateSettings(mode, true, value)` |
| 自启开关 | `getAutoStartState` 回填 + `setAutoStart` 写入 |
| `openPersistDlg()` | 从 `getWhitelistContent()` 拉真实持久化列表 |
| "编辑白名单文件" `<a>` | 绑 `openWhitelistInNotepad()` |
| "打开配置文件夹" `<a>` | 绑 `openConfigFolder()`（并改文案 `%APPDATA%\MemTrayCN` → `Traynexus`） |
| `openGithub()` | 调 `openUrl("https://github.com/traynexus/traynexus")` |
| `findDisplays()` | 维持 mock（亮度 P2，不做） |

### 3.4 接收后端推送（`onMessage`）
- `type=memory` → 更新 `window.__memPct`、速览/概览/标题栏/tooltip 数字
- `type=battery` → 更新 `window.__battPct`、速览/概览电池数字
- 推送时重算托盘 icon SVG 的 `stroke-dashoffset`（HTML 内的双环 SVG）

### 3.5 给无 id 的关键 DOM 元素加 id
为便于 JS 更新，给这些元素补 id（不改样式）：
- 速览面板内存行、电池行（`.qm-name span` / `.qm-val`）
- 概览 4 张卡片的 `.big` / `.sub` / `.bar i`
- 标题栏 `.tt`
- 两个 tooltip `#leftTip` / `#rightTip`（已有）

## 第四部分：充电模式 OEM WMI（按你要求尝试真实控制）

### 4.1 新增 `BatterySettings`（并入 `Settings.cs`）
- `ChargeLimit`(int, 默认 80)、`ChargeMode`(int: 0满充/1均衡/2保养)
- 持久化到 `settings.ini`
- `BridgeApi.UpdateSettings` 扩展接收充电参数

### 4.2 新增 `OemChargeController.cs`
- 检测 OEM：WMI 查 `Win32_ComputerSystem.Manufacturer`
- Lenovo：`root\WMI` 的 `Lenovo_SetFeature` / `LEN_BATTERY_METHODS`
- Dell：`root\wmi` 的 `Dell_SMBIOSSettings`
- HP：`root\wmi` 的 `HP_Battery` 
- ASUS：`root\wmi` 的 `ASUS_WMI`
- 每家尝试设置充电阈值，失败则记录"不支持"
- `BridgeApi` 新增 `SetChargeLimit(int percent)` / `GetChargeCapability()` 方法

### 4.3 前端充电模式接线
- `selMode(m)` / `bcSync()` 调 `SetChargeLimit()`
- 不支持时 `GetChargeCapability()` 返回 false → 三选项灰显 + tooltip 提示
- 健康报告弹窗的容量/循环/温度维持占位（Win32_Battery 拿不到）

## 第五部分：维持 mock 的功能（明确标注）

这些按你的选择本次不动，保持 HTML 现有 mock 行为：
- **亮度**：`findDisplays()` 维持写死"2个显示器"，滑块仅改 DOM
- **调度规则**：8 条规则表格维持前端本地增删改，不接后端引擎、不持久化
- **电池校准**：`startCalibrate()` 维持 `setInterval` 假动画
- **问题反馈**：`submitFeedback()` 维持假成功提示

## 验证方式
1. `build.bat` 编译通过
2. 运行 `bin/Traynexus.exe`，DevTools Console 执行 `await TraynexusBridge.getMemorySnapshot()` 返回真实内存
3. 速览面板内存数字 = 真实内存（非 36%）
4. 点"一键释放"后内存数字下降，结果弹窗显示真实释放量
5. 释放面板 = 真实进程列表（非 15 个假数据）
6. 托盘图标呈 logo.svg 渐变玻璃风，内环随电池电量变化
7. 切换充电模式后重启，模式保持；不支持 OEM 时选项灰显
8. 自启开关拨动后任务计划程序里 `Traynexus_AutoStart` 出现/消失
